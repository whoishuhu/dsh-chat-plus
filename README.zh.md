# dsh-chat-plus：对话增强

`dsh-chat-plus` 是 DeepSeek Harness 的会话操作插件，提供类似 WorkBuddy 的「原会话内重新生成 + 多版本切换」，并补充消息编辑、回退、软删除和会话回收站。

## 功能

### 回复版本

- 只对最后一轮提供重新生成按钮。
- 重新生成不会新建会话，侧边栏保持不变。
- 同一轮的多个回复可用 `< 1/2 >` 和键盘左右键切换。
- 当前版本显示生成模型和时间。
- 切换版本后，后续对话基于当前选中的版本。
- 如果原回复调用过工具，重新生成前会提示工具可能再次执行；提示不阻止操作。

### 消息操作

- 用户问题下方支持编辑、回退、复制和删除。
- 编辑任意一轮时，后续轮次会被软删除；原图片和文件可选择保留。
- 回退会删除当前节点及之后的轮次，并将原问题放回输入框。
- 删除回复会删除该版本的回复、思考和工具调用，但保留问题。
- 删除问题会删除整轮及其所有回复版本。
- 支持勾选多条消息后批量删除。

### 会话回收站

- 会话菜单的「删除会话」位于「归档会话」之后。
- 删除会话会先停止运行中的工作，再放入回收站。
- 工作区下方提供回收站入口。
- 支持还原、单条永久删除和清空回收站。
- 子代理会话随父会话级联处理。

## 重要边界

- 消息删除是软删除：内容离开模型上下文和聊天显示，但 append-only 原始日志不会改写，不能通过插件恢复。
- 版本切换会向日志追加选中版本的副本，因此日志长度可能增加；冷启动后仍可读取。
- 重新生成会再次执行这一轮的工具。文件改动、命令执行等副作用不会自动撤销。
- 回收站里的永久删除不可恢复，会删除会话日志、投影缓存和关联的子代理会话。
- 插件接管用户消息气泡以提供操作按钮；DSH 聊天组件改版时，插件可能需要适配。

## 安装

通过 DSH 插件市场搜索 `dsh-chat-plus`，或用插件管理器安装 npm 包。安装后重启 DSH 并刷新 Web 页面。
