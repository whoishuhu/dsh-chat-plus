# dsh-chat-plus: улучшение чата

[中文](README.zh.md) · [English](README.md) · [Архитектура](ARCHITECTURE.md)

Добавляет в DeepSeek Harness повторную генерацию в той же сессии, переключение версий, редактирование вопросов, откат, мягкое удаление и корзину сессий.

## Возможности

- Повторная генерация последнего хода и переключение `< 1/2 >`
- Модель, время генерации и переключение стрелками
- Предупреждение о возможном повторном запуске инструментов
- Мягкое удаление ответов, рассуждений, инструментов и целых ходов
- Редактирование любого вопроса с сохранением вложений
- Откат и восстановление вопроса в поле ввода
- Корзина: восстановление, окончательное удаление и очистка
- Каскадная обработка дочерних субагентов

Исходный append-only журнал не изменяется. Окончательное удаление необратимо.
