# dsh-chat-plus：チャット強化

[中文](README.zh.md) · [English](README.md) · [Architecture](ARCHITECTURE.md)

DeepSeek Harness に、同じセッション内での回答再生成とバージョン切り替え、質問の編集、ロールバック、ソフト削除、セッションごみ箱を追加します。

## 主な機能

- 最新ターンの再生成と `< 1/2 >` バージョン切り替え
- モデル名・生成時刻の表示、左右キー操作
- ツール再実行の警告
- 質問・回答・思考・ツール呼び出しのソフト削除
- 任意ターンの質問編集と添付ファイル保持
- ロールバックと入力欄への質問復元
- セッションのごみ箱、復元、完全削除、空にする操作
- 子サブエージェントのカスケード処理

元の append-only ログは書き換えません。完全削除は復元できません。
