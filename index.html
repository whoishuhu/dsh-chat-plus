One session · three answer versions · one active context
01 / REGENERATE

Try another answer

Regenerate the latest turn without creating another session. Tool use is called out before a rerun.

02 / SWITCH

Compare versions in place

Use the version switcher or arrow keys. Follow-up turns use the selected answer as context.

03 / EDIT

Edit the original question

Change a historical prompt in its message row. Later turns are removed only after confirmation.

04 / ROLLBACK

Return to a turn

Roll back later context and restore the original prompt to the official composer.

05 / DELETE

Clean up messages

Soft-delete a reply or a whole question/reply turn. Select multiple items for batch deletion.

06 / RECYCLE BIN

Recover sessions

Move sessions to a recycle bin, restore them, or permanently delete one or empty the bin.

Built for DSH's append-only sessions

Message soft deletion preserves the raw log. Permanent session deletion is explicit and irreversible.
